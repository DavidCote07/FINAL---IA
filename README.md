# SEMINARIO IA - Proyecto Final

Repositorio del proyecto final de SEMINARIO IA. Contiene el backend NestJS en `sepe-campo-backend/` y la documentación del sistema en `DOCS/`.

## Estructura del repositorio

- `DOCS/` - especificaciones y documentación del proyecto.
- `sepe-campo-backend/` - aplicación backend NestJS.

## Comandos útiles

Desde `sepe-campo-backend/`:

```bash
npm install
npm run start:dev
npm run test
```
